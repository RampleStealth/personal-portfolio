# AI Engineer Portfolio

A premium, case-study-led Next.js portfolio for an AI Automation Engineer and product-minded full-stack builder.

## Customize

- Update identity, contact links, and location in `data/profile.ts`.
- Replace the sample case studies and project links in `data/projects.ts`.
- Replace the interface mockups in `components/project-visual.tsx` with real project screenshots when available.

## Run locally

```bash
npm install
npm run dev
```

## Production validation

```bash
npm run build
```
